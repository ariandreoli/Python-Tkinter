- Cumplimiento de los Requisitos del Trabajo:

Este repositorio contiene la versión modificada y mejorada de un programa en Python para enviar correos electrónicos a través de una ventana gráfica. Se han completado todos los puntos solicitados en la consigna:

1. Se creó una copia de trabajo (fork) a partir del proyecto original para continuar su desarrollo.2.  Se configuró una cuenta propia para poder realizar los envíos desde la aplicación.
3. Se rediseñó el aspecto visual incorporando imágenes dentro de la ventana del programan.
4. Se agregó una lista de opciones (OptionMenu) que incluye los correos de profesores y cuenta personal, permitiendo también escribir manualmente cualquier otra dirección.
5. Se compiló la aplicación para poder usarse sin necesidad de abrir el código fuente.
6. Se realizaron múltiples avances en Git explicando cada cambio realizado durante el desarrollo.


- Herramientas Utilizadas

Para llevar a cabo este proyecto se utilizaron las siguientes herramientas:
- SMTP, Simple Mail Transfer Protocol por sus siglas en inglés, es un protocolo o conjunto de reglas 
de comunicación que utilizan los servidores de correo electrónico para enviar y recibir e-mails.
- Label y Entry, utilizados para mostrar los textos explicativos e insertar campos de texto de una sola línea para el destinatario y el asunto.
- OptionMenu, un menú desplegable implementado para seleccionar correos predefinidos.
- StringVar, Variables especiales de Tkinter usadas para capturar y leer de forma dinámica la opción elegida en el menú
